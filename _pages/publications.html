--- layout: archive title: "Publications" permalink: /publications/ author_profile: true scripts: [pub-filters, cite] --- {% include base_path %} {% comment %} Cards are generated from the _publications collection - one source of truth. To add a paper, add a file to _publications/ with: category (manuscripts | theses), date, venue (or thesis_type + institution), authors, topics, and optionally paperurl / bibtexurl / bibtex / citation / supervisor. Card markup lives in _includes/pub-card.html. Sections are grouped by year, newest first. The topic chips are built from every `topics` entry and are revealed by assets/js/pub-filters.js. {% endcomment %} {% assign publications = site.publications | sort: "date" | reverse %}
